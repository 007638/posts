项目简介：通过用react构建前端页面,实现用户注册登录，帖子列表，发布帖子，查看帖子和评论，个人信息，我的帖子，我的回帖等页面。

## 环境
- React（Create React App）
- react-router-dom（页面路由）

## 页面列表
| 路径 | 页面 |
| --- | --- |
| /register | 注册页 |
| /login | 登录页 |
| /list | 帖子列表页 |
| /create | 发布帖子页 |
| /post/:id | 帖子详情页 |
| /profile | 个人信息页 |
| /my/posts | 我的帖子 |
| /my/comments | 我的回帖 |
| /registersuccess | 注册成功页 |

## 安装步骤
1. 克隆项目到本地：
```
git clone https://github.com/007638/posts.git
```
## 安装依赖并启动
```
cd posts
npm install
npm run dev
```
